**每日打卡 · 工具简介**

一款纯离线、可添加到手机主屏幕的打卡记录工具。所有数据仅保存在浏览器本地，无需联网，打开即用。

**核心功能**
- 支持多个打卡项目，可自定义名称、开始日期和总天数。
- 打卡频率灵活：每日1次、2次（上午/下午）、3次（上午/中午/下午），时段名称可自定义。
- 长按日期可锁定/解锁单日，长按删除按钮可锁定删除，防止误操作。
- 支持为每天添加文字备注（限200字），记录心情或细节。
- 自动统计连续打卡天数、最长连续天数，并展示最近30天完成图表。
- 超过60天的项目自动按月折叠，1000天也能流畅浏览。
- 自动适配系统深色模式，夜间使用更舒适。
- 支持导出/导入JSON备份，删除后5秒内可撤销，也可随时编辑已有项目。

**使用提示**
点击浏览器“添加到主屏幕”即可像APP一样使用。建议定期导出备份，防止本地数据丢失。
