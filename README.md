# 打卡工具

一款离线优先的打卡与记录 App。数据只保存在设备本地，运行中不主动联网，无广告，打开即用。

## 下载

安卓手机可直接安装（两个地址内容相同，选能打开的即可）：

- GitHub：[下载最新版 APK](https://github.com/ZJL2221/Daily-check-in/releases/latest)
- Gitee：[下载 v1.2 APK](https://gitee.com/JLZZZ/Daily-check-in/releases/download/v1.2/app-release.apk)

首次安装需在系统设置中允许「安装未知来源的应用」。

> 最初的单文件网页版保留在 [`v0.1`](https://github.com/ZJL2221/Daily-check-in/releases/tag/v0.1) 标签中。

## 功能

新建时先选类型，两类各有各的用法。

**每日打卡** —— 按天记录进度

- 多项目管理：每个项目可自定义名称、开始日期、总天数和打卡频率
- 三种打卡频率：每日 1 次 / 2 次 / 3 次，多次模式的时段名称可自定义
- 打卡提醒（选填）：给每个时段单独设提醒时间。到点没打卡先提醒一次，之后每 10 分钟补一次，共 3 次
  - 打卡后：只撤该时段当天剩下的提醒，其他时段照常
  - 通知按钮：「今天不再提醒」停掉当天全部时段；「去打卡」直接跳到对应日期和时段
  - 改时间或删时间：旧提醒会自动撤掉
  - 提前排 14 天，打开 App 或回到前台自动续排
- 每日备注：每天可添加 200 字以内的文字备注；锁定的日期不能编辑备注
- 天数调整：支持 +1 / +7 / +30 天与 -1 / -7 / -30 天，减少天数时自动清理末尾的记录
- 按月折叠：日期跨月即分组折叠，长周期项目也能流畅浏览

**记录清单** —— 一行一条，可打勾

- 不设日期，想记什么记什么
- 点整行打勾 / 取消，已完成变灰加删除线
- 每条都能单独改文字、删除，删除前会确认
- 底部「＋ 添加一条」：弹出输入框，点「确定」可连续录入，点「完成」收起

**外观与设置**（右上角「!」→「功能」）

- 12 套主题：经典紫、森林绿、海盐蓝、落日橙、樱花粉、薄荷青、蜜桃乌龙、香芋拿铁、抹茶奶绿、雾灰蓝、晚霞、极光
- 字体大小：70% ~ 130% 七档，默认 100%
- 开屏动画：可关闭，关闭后启动直接进入主界面
- 深色模式：跟随系统

**两类通用**

- 锁定机制：长按单项可锁定或解锁，卡片顶部支持一键锁定全部；长按删除按钮切换删除锁定，防止误删
- 导入导出：可导出全部或单个项目，导入支持「合并导入」与「完全替换」两种方式
- 使用说明：右上角「!」里分「使用说明 / 功能」两张卡片；收不到提醒时可查底部的「问题总览」
- 返回键处理：有弹窗时优先关闭弹窗，避免误退出

## 技术栈

前端为原生 HTML / CSS / JavaScript，无框架，通过 Capacitor 打包为安卓应用。
数据存储使用 Capacitor Preferences，导出文件使用 Filesystem + Share。
打卡提醒使用 Capacitor Local Notifications，由系统闹钟触发，全程不联网。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构与全部弹窗 |
| `style.css` | 全部样式（含 12 套主题与深色模式） |
| `lib.js` | 工具函数、存储层与纯业务逻辑（不依赖 DOM） |
| `app.js` | 业务逻辑、渲染、事件、提醒排程与弹窗控制 |

`lib.js` 完全不依赖 DOM，可脱离浏览器直接做单元测试。

## 说明

数据保存在设备本地，卸载应用会一并清除，请定期导出备份。

打卡提醒需要系统通知权限。国产系统（小米 / 华为 / OPPO / vivo 等）还需要在系统设置里手动打开本应用的「自启动」，否则退出 App 后系统无法把通知送来。

提醒只能提前排进系统闹钟（一次排 14 天），所以超过 14 天没打开过 App 会暂停提醒，打开一次就自动续上。收不到提醒时，可在 App 内「右上角 ! → 提醒设置 / 问题总览」逐项检查。
